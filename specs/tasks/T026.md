# T026 — Export Android AAB (Signed) + Web HTML5 for itch.io

**Phase**: 5 — Screens, Save, Export
**Session estimate**: 90 min

## Input
- T001–T025 complete: game is feature-complete and tested on device
- Android keystore generated and stored outside the git repo
- AdMob plugin installed (T025)
- All 6 `.ogg` audio files present (T024)

## Steps

### Part A — Generate Android keystore (one-time, if not already done)

```bash
keytool -genkey -v \
  -keystore word-storm.keystore \
  -alias word-storm \
  -keyalg RSA -keysize 2048 \
  -validity 10000
```

Store the `.keystore` file at a path OUTSIDE the git repository (e.g. `~/keystores/word-storm.keystore`).

Set environment variables (add to `~/.zshrc` or CI secrets):
```bash
export WORD_STORM_KEYSTORE_PATH="/Users/you/keystores/word-storm.keystore"
export WORD_STORM_KEY_ALIAS="word-storm"
export WORD_STORM_KEY_PASSWORD="your-password"
export WORD_STORM_STORE_PASSWORD="your-password"
```

### Part B — Configure export_presets.cfg

Ensure these presets exist with correct settings:

```ini
[preset.0]
name="Android Release (AAB)"
platform="Android"
export_filter="all_resources"
exclude_filter="specs/*,docs/*,build/*,.git/*"
options/package/unique_name="com.wordstorm.game"
options/package/name="Word Storm"
options/screen/orientations=1
options/custom_build/use_custom_build=true   # required for AdMob
options/keystore/release=$WORD_STORM_KEYSTORE_PATH
options/keystore/release_user=$WORD_STORM_KEY_ALIAS
options/keystore/release_password=$WORD_STORM_KEY_PASSWORD

[preset.1]
name="Android APK (sideload)"
platform="Android"
# same as preset.0 but export_path targets .apk

[preset.2]
name="Web HTML5"
platform="Web"
export_filter="all_resources"
exclude_filter="specs/*,docs/*,build/*,.git/*"
options/progressive_web_app/enabled=false
```

### Part C — Pre-export checklist

Run through each item before exporting:

```
[ ] AdManager.gd: TEST_MODE = false, PROD_REWARDED_ID set via env var
[ ] All .ogg files present: ls assets/audio/sfx/*.ogg | wc -l == 6
[ ] Word list present: wc -l assets/data/words_en.txt >= 50000
[ ] specs/ and docs/ have .gdignore files
[ ] project.godot: renderer = "mobile"
[ ] No debug print statements that reveal internal state (search: grep -r "print(" scripts/)
[ ] SaveGame path is user:// not res://
[ ] Keystore env vars are set in current shell
```

### Part D — Headless export commands

Create `docs/build.md` with the full build commands:

```bash
#!/bin/bash
# Run from the word-storm/ project root

# Required env vars: WORD_STORM_KEYSTORE_PATH, WORD_STORM_KEY_ALIAS,
#                    WORD_STORM_KEY_PASSWORD, ADMOB_APP_ID, PROD_REWARDED_ID

mkdir -p build/android build/web

# Android APK (sideload / itch.io)
godot --headless --export-release "Android APK (sideload)" build/android/WordStorm.apk

# Android AAB (Play Store)
godot --headless --export-release "Android Release (AAB)" build/android/WordStorm.aab

# Web HTML5 (itch.io browser)
godot --headless --export-release "Web HTML5" build/web/index.html
```

### Part E — Post-export size check

```bash
# APK must be ≤ 30 MB
APK_SIZE=$(stat -f%z build/android/WordStorm.apk 2>/dev/null || stat -c%s build/android/WordStorm.apk)
if [ "$APK_SIZE" -gt 31457280 ]; then
    echo "ERROR: APK exceeds 30 MB ($APK_SIZE bytes)" >&2
    exit 1
fi
echo "APK size: $(( APK_SIZE / 1024 / 1024 )) MB — OK"
```

### Part F — Device install and smoke test

```bash
# Install APK on connected Android device
adb install build/android/WordStorm.apk

# Launch and verify
adb shell am start -n com.wordstorm.game/com.godot.game.GodotApp
```

Manual smoke test on device:
- App opens in ≤ 5 s from cold start
- Title screen renders correctly in portrait
- Play a full game: tiles fall, words validate, score counts, lives track
- GameOver screen: ad slot behaves correctly (live ad or graceful no-fill)
- Play Again: restarts correctly

### Part G — Web HTML5 test

Open `build/web/index.html` in a browser via a local server:
```bash
python3 -m http.server 8080 --directory build/web
# open http://localhost:8080
```

Verify: game loads, touch emulation works with mouse, word validation runs, no console errors.

## Acceptance Criteria
- `build/android/WordStorm.apk` exists and is ≤ 30 MB: `stat -c%s` returns ≤ 31,457,280 bytes
- `build/android/WordStorm.aab` exists (for Play Store upload)
- APK installs on a physical Android device (API 26+) via `adb install` without errors
- Cold start on device: app is playable within 5 seconds
- Full game loop runs on device: Start → Play → Game Over → Play Again
- `build/web/index.html` loads in Chrome/Firefox via local HTTP server; game is playable
- Keystore password is NOT in `export_presets.cfg` or any committed file (uses env var reference)
- `docs/build.md` documents all build steps and required env vars

## Notes
- `build/` is gitignored — never commit APK/AAB/HTML build artifacts
- For Play Store submission: the AAB (not APK) is required; upload `WordStorm.aab`
- Web export does NOT support AdMob — ads are silently skipped on the Web build (graceful no-op via `Engine.has_singleton("AdMob")` check)
- If APK exceeds 30 MB: audit with `godot --headless --export-release` and inspect the `.apk` contents with `unzip -l` to identify the largest assets; compress or remove accordingly

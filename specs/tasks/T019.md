# T019 — Build StartScreen.tscn (Logo, Best Score, Star Particles, Play Button)

**Phase**: 5 — Screens, Save, Export
**Session estimate**: 90 min

## Input
- T009 complete: `GameManager.gd` has `start_game(type)` method and `SessionType` enum
- T023 complete (or stub OK): `SaveGame.get_best_score()` and `SaveGame.get_daily_result()` callable
- T003 complete: `assets/fonts/ui_font.ttf` available
- T005 complete: `Palette.gd` colour constants available

## Steps

### Part A — StartScreen.tscn scene tree

Build `scenes/screens/StartScreen.tscn`:
```
StartScreen (CanvasLayer)
├── Background (ColorRect)             ← full 400×680, color = Palette.BACKGROUND
├── Logo (Label)                       ← text = "WORD\nSTORM", font size 52, bold, centred, y = 120
├── BestScore (Label)                  ← text = "Best: 0", font size 20, centred, y = 240
├── DailyBadge (Label)                ← text = "Today: —" / "Done Today ✓", font size 16, y = 270
├── StarParticles (GPUParticles2D)    ← ambient idle effect, NOT one_shot, runs continuously
├── PlayButton (Button)               ← text = "PLAY", size 180×56, centred, y = 340
├── DailyButton (Button)              ← text = "DAILY CHALLENGE", size 180×56, centred, y = 412
├── SettingsButton (Button)           ← text = "⚙", size 48×48, top-right corner (x=340, y=12)
└── HouseAdBanner (Label)            ← text = "Also play: Deep Break →", bottom of screen, y=640
```

If no sprite asset is available for the logo, use a large Label with stylised text — this is acceptable for Phase 5.

### Part B — StarParticles (ambient effect)

`GPUParticles2D` settings:
- `one_shot = false`, `emitting = true` from scene load
- `amount = 40`, `lifetime = 4.0`
- `Process Material` (`ParticleProcessMaterial`):
  - `emission_shape = BOX`, box extents = `(200, 340, 0)` — fills full screen
  - `direction = Vector3(0, 1, 0)` (drift downward slowly)
  - `initial_velocity_min = 10.0`, `initial_velocity_max = 30.0`
  - `scale_min = 2.0`, `scale_max = 5.0`
  - colour gradient: white → transparent

### Part C — StartScreen.gd

Create `scripts/StartScreen.gd`:

#### 1. `_ready()`
```gdscript
$BestScore.text = "Best: %d" % SaveGame.get_best_score()

var today := Time.get_date_string_from_system().replace("-", "")
var daily_score := SaveGame.get_daily_result(today)
if daily_score >= 0:
    $DailyBadge.text = "Done Today ✓ (%d)" % daily_score
    $DailyButton.disabled = true
else:
    $DailyBadge.text = "Today's challenge ready!"
```

#### 2. Button signals
```gdscript
$PlayButton.pressed.connect(func(): GameManager.start_game(GameManager.SessionType.CLASSIC))
$DailyButton.pressed.connect(func(): GameManager.start_game(GameManager.SessionType.DAILY))
$SettingsButton.pressed.connect(_show_settings)
```

#### 3. `_show_settings()`
- Load and add `SettingsOverlay.tscn` as a child (T021)
- For now: just print "Settings pressed" if T021 isn't done yet

#### 4. Register StartScreen as the default scene loaded by Main.gd on TITLE state
```gdscript
# In Main.gd:
GameManager.State.TITLE → load StartScreen.tscn
```

## Acceptance Criteria
- App launches to StartScreen showing the logo, "Best: 0" (first run), and both buttons
- `SaveGame.get_best_score()` returning 150 → displays "Best: 150"
- If `get_daily_result(today)` returns -1: DailyButton is enabled
- If `get_daily_result(today)` returns a positive score: DailyButton is disabled and shows "Done Today ✓"
- Tapping "PLAY": game transitions to GameScreen and `GameManager.state == PLAYING`
- Star particles drift across the background continuously
- No GDScript errors; `scenes/screens/StartScreen.tscn` and `scripts/StartScreen.gd` committed

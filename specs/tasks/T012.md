### Part B — GameScreen.gd

Create `scripts/GameScreen.gd`:

#### 1. `_ready()`
- Get references to all Column nodes, WordTray, SubmitButton, ClearButton
- Connect all Column `pile_overflow` → `GameManager.lose_life()`
- Connect all Column `tile_spawned` (new signal from Column.gd: emit when tile is added to scene) → `_on_tile_spawned(tile)`
- Connect SubmitButton `pressed` → `WordTray.submit()`
- Connect ClearButton `pressed` → `WordTray.clear()`
- Connect `WordTray.word_submitted` → `WordValidator.validate_submission(tiles)`
- Connect `WordValidator.word_valid` → `_on_word_valid(word, tiles, score)`
- Connect `WordValidator.word_invalid` → `_on_word_invalid(word)`
- Connect `GameManager.game_over` → `_on_game_over()`
- Connect `GameManager.speed_increased` → `_on_speed_increased(new_speed)`

#### 2. `_on_tile_spawned(tile)`
- Connect `tile.tile_tapped` → `WordTray.add_tile(tile)`
- Call `GameManager.register_tile(tile)`

#### 3. `_on_word_valid(word, tiles, score)`
- Calls `ScoreManager.award(tiles)` (stub in T014; just add a `print` for now)
- Calls `tile.destroy()` on each tile in `tiles`
- Calls `GameManager.unregister_tile(tile)` for each tile
- Clears the tray

#### 4. `_on_word_invalid(word)`
- Calls `WordTray.shake()` (shake + clear is handled inside shake's tween callback)

#### 5. `_on_game_over()`
- Calls `get_tree().change_scene_to_file("res://scenes/screens/GameOver.tscn")`

#### 6. `_on_speed_increased(new_speed)`
- Propagates to all Column nodes: `column.set_fall_speed(new_speed)`

#### 7. SubmitButton enabled state
- Connect `WordTray` to emit a signal `tray_changed(count: int)` when tile count changes
- `SubmitButton.disabled = count < 3`

### Part C — Set GameScreen as the scene Main.gd loads on start_game

Update `Main.gd` (or create it if missing):
```gdscript
extends Node

func _ready() -> void:
    GameManager.state_changed.connect(_on_state_changed)

func _on_state_changed(new_state) -> void:
    match new_state:
        GameManager.State.PLAYING:
            get_tree().change_scene_to_file("res://scenes/screens/GameScreen.tscn")
        GameManager.State.GAME_OVER:
            pass  # GameScreen handles the transition itself
```

## Acceptance Criteria
- Run GameScreen: 5 columns spawn tiles, tiles fall, tapping a tile adds it to WordTray
- Tapping "SUBMIT" with ≥ 3 letters in tray: `word_submitted` fires → WordValidator validates
- Spelling "CAT": tiles are destroyed, a `print` confirms valid word
- Spelling "ZZQ": WordTray shakes then clears
- "SUBMIT" button is disabled when fewer than 3 letters are selected
- "CLEAR" button deselects all tiles and empties the tray
- Losing 3 lives (wait for 3 column overflows): scene transitions to GameOver screen
- No GDScript errors; `scenes/screens/GameScreen.tscn` and `scripts/GameScreen.gd` committed

# T025 — Wire AdMob Rewarded Ad Plugin to GameOver Continue Button

**Phase**: 5 — Screens, Save, Export
**Session estimate**: 120 min

## Input
- T020 complete: `GameOver.tscn` has `ContinueAdButton` and calls `AdManager.load_rewarded()` / `show_rewarded()`
- T002 complete: `AdManager.gd` stub registered as autoload
- Android export preset configured (T001)
- Physical Android device or Android emulator available for live ad testing

## Steps

### Part A — Install Godot AdMob Plugin

The official plugin for Godot 4 + Android is `Poing Games/Godot AdMob Plugin` (or equivalent maintained fork).

1. Download the latest release `.zip` from the plugin's GitHub releases page
2. Extract and copy the `addons/` folder contents into `word-storm/addons/`
3. In Godot Editor: Project → Project Settings → Plugins → Enable "AdMob"
4. In Android export preset, add the required permissions:
   - `android.permission.INTERNET`
   - `android.permission.ACCESS_NETWORK_STATE`
5. In `export_presets.cfg`, add the AdMob App ID:
   ```ini
   options/gradle_build/gradle_build_enabled = true
   options/custom_gradle_properties = "admob_app_id=ca-app-pub-XXXXXXXXXXXXXXXXXX~XXXXXXXXXX"
   ```
   **IMPORTANT**: The real App ID must come from an environment variable, not hardcoded:
   ```bash
   # In build script / CI:
   export ADMOB_APP_ID="ca-app-pub-..."
   ```
   Use test App ID for development: `ca-app-pub-3940256099942544~3347511713`

### Part B — Replace AdManager.gd stub with real implementation

```gdscript
extends Node

signal ad_reward_granted
signal ad_unavailable

const TEST_MODE: bool = true   # set false before Play Store submission

const TEST_REWARDED_ID := "ca-app-pub-3940256099942544/5224354917"
const PROD_REWARDED_ID := ""   # set before release; loaded from env via export build

var _admob: Node = null
var _rewarded_loaded: bool = false

func _ready() -> void:
    if not Engine.has_singleton("AdMob"):
        push_warning("AdManager: AdMob singleton not found (non-Android build or plugin missing)")
        return
    _admob = Engine.get_singleton("AdMob")
    _admob.connect("rewarded_ad_loaded",    _on_rewarded_loaded)
    _admob.connect("rewarded_ad_failed_to_load", _on_rewarded_failed)
    _admob.connect("rewarded_ad_dismissed", _on_rewarded_dismissed)
    _admob.connect("user_earned_reward",    _on_user_earned_reward)

    # Configure halal-safe category exclusions in AdMob dashboard (not in code)
    # Dashboard: AdMob → Blocking Controls → General Categories
    # Block: Dating, Gambling, Alcohol, Financial Products, Music & Entertainment

func load_rewarded() -> void:
    if _admob == null:
        emit_signal("ad_unavailable")
        return
    var ad_unit_id := TEST_REWARDED_ID if TEST_MODE else PROD_REWARDED_ID
    _admob.load_rewarded_ad(ad_unit_id)

func show_rewarded() -> void:
    if not _rewarded_loaded or _admob == null:
        emit_signal("ad_unavailable")
        return
    _admob.show_rewarded_ad()

func _on_rewarded_loaded() -> void:
    _rewarded_loaded = true

func _on_rewarded_failed(_error_code: int) -> void:
    _rewarded_loaded = false
    emit_signal("ad_unavailable")

func _on_rewarded_dismissed() -> void:
    _rewarded_loaded = false
    # Do NOT grant reward on dismiss — only grant on user_earned_reward

func _on_user_earned_reward(_type: String, _amount: int) -> void:
    _rewarded_loaded = false
    emit_signal("ad_reward_granted")
```

### Part C — Halal content configuration

In AdMob Dashboard (not in code — this is a one-time manual setup):
1. AdMob → Blocking Controls → General Categories
2. Block: **Dating**, **Gambling & Betting**, **Alcoholic Beverages**, **Financial Services** (interest-based products), **Music & Entertainment** (if potentially contains prohibited content)
3. AdMob → Blocking Controls → Advertiser URLs — add any known non-compliant advertisers
4. Document the blocking configuration in `docs/admob-setup.md`

### Part D — Test on device

1. Export a debug APK: `godot --headless --export-debug "Android" build/android/WordStorm-debug.apk`
2. Install on device: `adb install build/android/WordStorm-debug.apk`
3. Play until game over → tap "Watch Ad → +1 Life"
4. Verify: test ad appears, completes, `ad_reward_granted` fires, game restores 1 life and returns to gameplay

## Acceptance Criteria
- On Android device: game over screen shows "Watch Ad → +1 Life" button
- Tapping the button: a test rewarded video ad plays to completion
- After ad completes: game restores 1 life, clears 50% of piles, and transitions back to GameScreen
- If ad fails to load (offline or no fill): "No ad available" label shows for 2 s then hides; game continues normally
- Dismissing the ad without completing it: no reward granted (no life restored)
- On non-Android (Web/Editor): AdMob singleton absent → `ad_unavailable` always fires gracefully
- `TEST_MODE` is `true` in committed code; a TODO comment marks it for release
- No GDScript errors; `scripts/autoloads/AdManager.gd` and `docs/admob-setup.md` committed

## Notes
- **Do NOT commit the real AdMob App ID or Ad Unit IDs** — use environment variables in CI and document the variable names in `docs/build.md`
- The plugin requires Gradle build enabled (`custom_build = true`) in the Android preset — this increases first-build time but is required for AdMob
- Category blocking in AdMob dashboard is manual and must be reviewed by the developer before going live — Claude Code cannot access the AdMob dashboard
- Test ad IDs from Google: use them during development, never in production

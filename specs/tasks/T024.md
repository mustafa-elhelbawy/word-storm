# T024 — Add Sound Effects (6 × .ogg Files)

**Phase**: 5 — Screens, Save, Export
**Session estimate**: 60 min

## Input
- T018 complete: `AudioManager.gd` wired and expecting `.ogg` files at `assets/audio/sfx/`

## Steps

The goal is to source or generate 6 short `.ogg` audio clips that are royalty-free, halal-safe, and under 200 KB each.

### Required files

| Filename | Event | Target duration | Character |
|----------|-------|----------------|-----------|
| `tile_land.ogg` | Tile hits pile zone | 0.1 s | Soft thud / click |
| `tile_select.ogg` | Player taps a tile | 0.05 s | Crisp tick |
| `word_valid.ogg` | Valid word submitted | 0.4 s | Upward chime / success |
| `word_invalid.ogg` | Invalid word rejected | 0.3 s | Low buzz / negative tone |
| `life_lost.ogg` | Column overflows | 0.5 s | Impact / alarm pulse |
| `game_over.ogg` | All lives gone | 1.0 s | Descending tone / stinger |

### Sourcing options (pick one per file)

**Option A — Freesound.org** (CC0 / CC BY 3.0 sounds):
- Search for "click", "chime", "buzz", "impact"
- Filter by License: CC0 (preferred) to avoid attribution requirement
- Download `.wav` or `.mp3`, convert to `.ogg` using ffmpeg:
  ```bash
  ffmpeg -i input.wav -c:a libvorbis -q:a 4 output.ogg
  ```

**Option B — jsfxr / sfxr.me** (procedural, always free):
- Open `sfxr.me` in browser
- Generate each sound type using the randomise buttons:
  - PICKUP/COIN → tile_select.ogg
  - JUMP → tile_land.ogg  
  - POWERUP → word_valid.ogg
  - HIT/HURT → word_invalid.ogg
  - EXPLOSION → life_lost.ogg
  - SYNTH → game_over.ogg
- Export as `.wav`, convert to `.ogg` with ffmpeg

**Option C — Godot's built-in AudioStreamGenerator** (pure code, no external files):
- Not recommended for this project — requires runtime synthesis which adds code complexity
- Only fall back to this if no other option is available before export

### Steps
1. Source all 6 clips using Option A or B
2. Convert each to mono `.ogg`, quality 4 (`-q:a 4` ≈ 128 kbps)
3. Verify file sizes: `ls -lh assets/audio/sfx/*.ogg` — each should be under 100 KB
4. Copy into `assets/audio/sfx/`
5. Open Godot editor — let it import all 6 `.ogg` files
6. Test by running the game and triggering each event — confirm audible output
7. Add a credit line in `docs/credits.md` for any CC BY sourced sounds
8. Commit all 6 `.ogg` files (NOT the `.import` files — they stay in `.gitignore`)

## Acceptance Criteria
- All 6 `.ogg` files exist in `assets/audio/sfx/`
- `ls -lh assets/audio/sfx/` shows 6 files, each < 200 KB
- Running the game: tapping a tile plays `tile_select.ogg` (audible)
- Submitting "CAT": `word_valid.ogg` plays
- Submitting "ZZQ": `word_invalid.ogg` plays
- Losing a life: `life_lost.ogg` plays with a red screen flash simultaneously
- Game over: `game_over.ogg` plays as scene transitions to GameOver screen
- `docs/credits.md` lists the source of each sound (even CC0 sources, for record-keeping)
- No GDScript errors; committed

## Notes
- Keep sounds short and punchy — mobile games need < 0.5 s feedback latency from event to perception
- Stereo not required: mono `.ogg` files are smaller and sound identical through mobile speakers
- If APK size is approaching the 30 MB limit, lower `-q:a` to 2 (≈ 80 kbps) — virtually indistinguishable on mobile
- Do NOT use MP3 format — `.ogg` is the required format per the constitution (lowest latency on Android)

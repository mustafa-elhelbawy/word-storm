# T010 — Build WordTray.tscn + WordTray.gd (Selection Array, 8-Slot Display)

**Phase**: 3 — Word Logic
**Session estimate**: 90 min

## Steps

### Part A — WordTray.tscn

Build `scenes/game/WordTray.tscn`:
```
WordTray (CanvasLayer, layer = 4)
├── Background (NinePatchRect)     ← dark panel, full-width, ~90px tall, anchored bottom
├── TileSlots (HBoxContainer)      ← 8 slots, separation 4px, centred horizontally
└── EmptyHint (Label)             ← "Tap letters to spell a word", shown when tray empty
```

Layout:
- Position: bottom of screen (y = 590), width 400px, height 90px
- `NinePatchRect` uses a simple programmatic `StyleBoxFlat` (rounded corners 8px, dark semi-transparent colour `Color(0.05, 0.05, 0.1, 0.85)`)
- `HBoxContainer` aligned centre; each slot is a `Label` with background `StyleBoxFlat`, size 48×48, centred text

### Part B — WordTray.gd

Create `scripts/WordTray.gd` and attach to scene root:

#### 1. Member variables
```gdscript
extends CanvasLayer

signal word_submitted(tiles: Array)

const MAX_TILES: int = 8

var _selected: Array = []   # ordered Array of LetterTile references
```

#### 2. `_ready()`
- Connect to `GameManager.state_changed` — clear tray when state leaves PLAYING
- Hide `EmptyHint` (shown when `_selected` is empty — inverted logic)

#### 3. `add_tile(tile) -> bool`
```gdscript
func add_tile(tile) -> bool:
    if _selected.size() >= MAX_TILES:
        return false
    if tile in _selected:
        remove_tile(tile)
        return true
    _selected.append(tile)
    tile.select()
    _refresh_display()
    return true
```
- Tapping a tile already in the tray removes it (toggle behaviour)

#### 4. `remove_tile(tile)`
- Removes tile from `_selected`, calls `tile.deselect()`, refreshes display

#### 5. `_refresh_display()`
- Updates each slot Label in `TileSlots` with the corresponding tile's letter
- Clears empty slots
- Shows/hides `EmptyHint` based on `_selected.is_empty()`
- Enables/disables SubmitButton (connected externally) — emit a signal or set a variable that GameScreen reads

#### 6. `get_word() -> String`
```gdscript
func get_word() -> String:
    return "".join(_selected.map(func(t): return t.letter))
```

#### 7. `submit()`
- Guards: `_selected.size() < 3` → return early (no submission)
- Emits `word_submitted(_selected.duplicate())`
- Does NOT clear yet — clearing happens after word_valid or word_invalid response

#### 8. `clear()`
- Calls `tile.deselect()` on all tiles in `_selected`
- Empties `_selected`
- Calls `_refresh_display()`

#### 9. `shake()` — invalid word feedback
```gdscript
func shake() -> void:
    var tween := create_tween()
    var bg := $Background
    for i in 3:
        tween.tween_property(bg, "position:x", bg.position.x + 8.0, 0.033)
        tween.tween_property(bg, "position:x", bg.position.x - 8.0, 0.033)
    tween.tween_property(bg, "position:x", 0.0, 0.033)
    tween.tween_callback(clear)
```
Total duration ≈ 0.2 s, 3 cycles, ±8px

### Part C — Connect tile_tapped → WordTray

In the GameScreen scene (or a temporary test scene), connect every Column's spawned tile's `tile_tapped` signal to `WordTray.add_tile(tile)`. This wiring lives in `GameScreen.gd` (T015 finalises this, but test it now with a basic scene).

## Acceptance Criteria
- Tap a falling tile: it appears in the WordTray as a letter in a slot
- Tap the same tile again: it disappears from the tray and deselects
- Tap 8 tiles: tray fills; 9th tap has no effect (8-tile cap enforced)
- `get_word()` returns the correct concatenated string in tap order
- `submit()` with fewer than 3 tiles selected: no signal emitted
- `submit()` with ≥ 3 tiles: `word_submitted` signal fires with the tile array
- `shake()` animates the Background ±8px 3 times over ~0.2 s then clears
- `EmptyHint` label is visible when tray is empty, hidden when any tile is selected
- No GDScript errors; committed

## Notes
- WordTray deliberately does NOT call WordValidator — it just emits `word_submitted`; validation is decoupled (T011 wires this)
- The SubmitButton and ClearButton nodes live in the GameScreen scene (T015), not inside WordTray — WordTray exposes `submit()` and `clear()` as callable methods

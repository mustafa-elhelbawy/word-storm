# T014 — Write ScoreManager.gd (Points Table, Combo, Best Score)

**Phase**: 4 — Scoring, Effects, HUD
**Session estimate**: 90 min

## Input
- T011 complete: `WordValidator.gd` emits `word_valid(word, tiles, raw_score)` and `word_invalid(word)`
- T012 complete: `GameScreen.gd` calls `ScoreManager.award(tiles)` on valid words
- T002 complete: `ScoreManager.gd` stub registered as autoload

## Steps

### 1. Replace stub `scripts/autoloads/ScoreManager.gd` with full implementation

```gdscript
extends Node

signal score_updated(new_score: int, delta: int)
signal combo_changed(multiplier: float)

const BASE_SCORES: Dictionary = { 3: 10, 4: 25, 5: 50 }
const BASE_SCORE_LONG: int = 100            # 6+ letters
const COMBO_RESET_SECONDS: float = 6.0

# Combo multiplier tiers: consecutive_valid_words → multiplier
const COMBO_TIERS: Array[Array] = [
    [0, 1.0],   # 0 consecutive → ×1
    [2, 1.5],   # 2+            → ×1.5
    [4, 2.0],   # 4+            → ×2
    [6, 3.0],   # 6+            → ×3
]

var score: int = 0
var best_score: int = 0
var combo_count: int = 0
var _combo_timer: float = 0.0
var _combo_active: bool = false
```

### 2. Implement `_process(delta)`
- Only active when `GameManager.state == State.PLAYING`
- If `_combo_active`: decrement `_combo_timer -= delta`; if `_combo_timer <= 0`: reset combo

### 3. Implement `reset()`
- Called by GameManager at `start_game()`
- Resets `score`, `combo_count`, `_combo_timer`, `_combo_active` to defaults
- Loads `best_score` from SaveGame: `best_score = SaveGame.get_best_score()`
- Emits `score_updated(0, 0)` and `combo_changed(1.0)`

### 4. Implement `award(tiles: Array) -> int`
```gdscript
func award(tiles: Array) -> int:
    var length := tiles.size()
    var base := BASE_SCORES.get(length, BASE_SCORE_LONG)

    # Letter bonus: sum of tile point values × 0.1 added as multiplier
    var letter_sum: int = 0
    for tile in tiles:
        letter_sum += tile.point_value
    var letter_bonus: float = 1.0 + letter_sum * 0.1

    # Combo multiplier
    combo_count += 1
    _combo_timer = COMBO_RESET_SECONDS
    _combo_active = true
    var multiplier := _get_combo_multiplier()

    var points := int(base * multiplier * letter_bonus)
    score += points

    if score > best_score:
        best_score = score
        SaveGame.set_best_score(best_score)

    emit_signal("score_updated", score, points)
    emit_signal("combo_changed", multiplier)
    return points
```

### 5. Implement `_get_combo_multiplier() -> float`
- Iterate `COMBO_TIERS` in reverse; return the multiplier for the highest tier ≤ `combo_count`

### 6. Implement `break_combo()`
- Called when `word_invalid` fires
- Resets `combo_count = 0`, `_combo_timer = 0.0`, `_combo_active = false`
- Emits `combo_changed(1.0)`

### 7. Wire connections in GameScreen.gd
- `WordValidator.word_valid` → `ScoreManager.award(tiles)` (pass tile array, not raw_score — ScoreManager recalculates)
- `WordValidator.word_invalid` → `ScoreManager.break_combo()`
- `GameManager.start_game` → `ScoreManager.reset()`

### 8. Commit `scripts/autoloads/ScoreManager.gd`; update `GameScreen.gd`

## Acceptance Criteria
- Spell 3-letter word ("CAT"): `score_updated` fires with `delta = 10` (no combo yet, standard tiles)
- Spell 4 consecutive valid words: `combo_changed` fires with `multiplier = 1.5` after 2nd, `2.0` after 4th
- After 6 s without a valid word: combo resets to ×1, `combo_changed(1.0)` fires
- Submit an invalid word: combo resets immediately
- Beat the previous best score: `SaveGame.get_best_score()` returns the new higher value
- Score never goes negative
- No GDScript errors; committed

## Notes
- `award()` always receives the raw `tiles` array — it computes both base score and letter bonus internally
- The `raw_score` emitted by `WordValidator.word_valid` is informational only; ScoreManager does its own calculation
- SaveGame is called here (T023 implements SaveGame.gd fully, but the stub's `set_best_score` is a no-op — that's fine for this phase)

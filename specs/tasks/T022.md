# T022 — Write Main.tscn + Main.gd (Scene Switcher)

**Phase**: 5 — Screens, Save, Export
**Session estimate**: 45 min

## Input
- T009 complete: `GameManager.gd` emits `state_changed(new_state)`
- T019 complete: `StartScreen.tscn` exists
- T012 complete: `GameScreen.tscn` exists
- T020 complete: `GameOver.tscn` exists

## Steps

### Part A — Main.tscn

Build `scenes/main/Main.tscn`:
```
Main (Node)              ← Main.gd attached
└── SceneContainer (Node)  ← active scene instance lives here
```

### Part B — Main.gd

Create `scripts/Main.gd`:

```gdscript
extends Node

const SCENES: Dictionary = {
    GameManager.State.TITLE:     "res://scenes/screens/StartScreen.tscn",
    GameManager.State.PLAYING:   "res://scenes/screens/GameScreen.tscn",
    GameManager.State.GAME_OVER: "res://scenes/screens/GameOver.tscn",
}

var _current_scene: Node = null

func _ready() -> void:
    GameManager.state_changed.connect(_on_state_changed)
    _switch_to(GameManager.State.TITLE)

func _on_state_changed(new_state: GameManager.State) -> void:
    if SCENES.has(new_state):
        _switch_to(new_state)

func _switch_to(state: GameManager.State) -> void:
    if _current_scene:
        _current_scene.queue_free()
    var packed: PackedScene = load(SCENES[state])
    _current_scene = packed.instantiate()
    $SceneContainer.add_child(_current_scene)
```

### Part C — Set Main.tscn as the project's main scene

In `project.godot`:
```ini
[application]
run/main_scene = "res://scenes/main/Main.tscn"
```

(Set via Editor: Project Settings → Application → Run → Main Scene)

### Part D — Update GameScreen.gd to remove its own scene-switch calls

`GameScreen.gd._on_game_over()` previously called `change_scene_to_file("GameOver.tscn")` directly. Remove this — Main.gd now handles all transitions via `GameManager.state_changed`.

```gdscript
# GameScreen.gd — remove:
func _on_game_over() -> void:
    get_tree().change_scene_to_file("res://scenes/screens/GameOver.tscn")

# No replacement needed — Main.gd catches game_over via state_changed
```

## Acceptance Criteria
- Launch app: starts on StartScreen (state = TITLE)
- Tap "PLAY": transitions to GameScreen (state = PLAYING)
- Lose 3 lives: transitions to GameOver (state = GAME_OVER)
- Tap "PLAY AGAIN": back to GameScreen (new CLASSIC game)
- No scene transition uses `change_scene_to_file` directly — all routing goes through GameManager state
- `Main.tscn` is set as the main scene in `project.godot`
- All three scenes load and unload cleanly (no orphaned nodes in Remote Scene Tree)
- No GDScript errors; `scenes/main/Main.tscn` and `scripts/Main.gd` committed

## Notes
- `State.WAITING` is not routed — it's an internal state that GameManager uses between scene loads; add it as a no-op match arm if needed
- `_switch_to` uses `load()` (blocking) not `ResourceLoader.load_threaded_request()` — scenes are small, so blocking loads are acceptable and keep the code simple
- Future: `SettingsOverlay` is not routed via Main — it's added as a child of whichever scene opens it

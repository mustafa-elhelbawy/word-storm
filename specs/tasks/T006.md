# T006 — Build LetterTile.tscn Scene

**Phase**: 2 — Core Tile System
**Session estimate**: 45 min

## Input
- T001–T005 complete: project opens, folder structure exists, `Palette.gd` is available

## Steps
Build `scenes/game/LetterTile.tscn` with this node tree:

```
LetterTile (Area2D)                    ← root; LetterTile.gd attached in T007
├── CollisionShape2D                   ← RectangleShape2D, size = (64, 64)
├── TileBackground (ColorRect)         ← size = (64, 64), default color = Palette.COL_COLOURS[0]
├── LetterLabel (Label)                ← centred, font size 28, bold weight
└── PointsLabel (Label)               ← bottom-right, font size 11, semi-transparent
```

Detailed setup:
1. Create scene root as `Area2D` named `LetterTile`
2. Add `CollisionShape2D` child → create `RectangleShape2D` resource, set extents to `(32, 32)` (half of 64px tile)
3. Add `ColorRect` child named `TileBackground` — size `(64, 64)`, anchored top-left at `(-32, -32)` relative to Area2D origin so the tile is centred on its collision shape
4. Add `Label` child named `LetterLabel`:
   - `text = "A"` (placeholder)
   - `horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER`
   - `vertical_alignment = VERTICAL_ALIGNMENT_CENTER`
   - Assign `assets/fonts/ui_font.ttf` at size 28
   - Anchor to fill `TileBackground`'s rect
5. Add `Label` child named `PointsLabel`:
   - `text = "1"` (placeholder)
   - Anchor: bottom-right of tile, offset `(-4, -2)` from bottom-right corner
   - Font size 11, modulate alpha 0.7
6. Set `Area2D` → `input_pickable = true` (required for `input_event` signal)
7. Save scene to `scenes/game/LetterTile.tscn`

## Acceptance Criteria
- `scenes/game/LetterTile.tscn` exists and opens in editor without errors
- Scene preview shows a 64×64 coloured square with a centred letter and a small subscript number in the bottom-right
- CollisionShape2D bounding box exactly matches the TileBackground rect (no gap)
- No GDScript errors in the Output panel when opening the scene
- Scene is committed in git

## Notes
- Do NOT attach a script yet — that is T007
- The `Area2D` root (not `CharacterBody2D`) is intentional: tiles fall independently per column and never collide with each other, so physics bodies would add overhead with zero benefit
- Tile size is 64×64 logical px, which is ≥ 48dp at 160 dpi baseline — satisfies Android touch target guidelines

# T002 — Create Full Folder Structure

**Phase**: 1 — Environment Setup
**Session estimate**: 20 min

## Input
- T001 complete: `project.godot` exists and opens without errors

## Steps
Create the following directory tree under `word-storm/`. Add a `.gdkeep` placeholder file in each empty leaf directory so Git tracks them.

```
scenes/
  main/
  screens/
  game/
  overlays/
  effects/

scripts/
  autoloads/

assets/
  textures/
  audio/
    sfx/
  fonts/
  data/

docs/
build/
  android/
  web/
```

2. Create `docs/.gdignore` — prevents `docs/` from being included in APK
3. Create `specs/.gdignore` — prevents `specs/` from being included in APK
4. Create `.gitignore` additions:
   ```
   build/
   .godot/
   *.import
   ```
5. Create stub autoload scripts (each is `extends Node` with empty `_ready()`) in `scripts/autoloads/`:
   - `GameManager.gd`
   - `ScoreManager.gd`
   - `WordValidator.gd`
   - `SaveGame.gd`
   - `ParticleManager.gd`
   - `AudioManager.gd`
   - `AdManager.gd`
   - `ThemeManager.gd`
6. Register all 8 autoloads in `project.godot` via Project Settings → Autoload (GameManager first)
7. Commit everything

## Acceptance Criteria
- All directories exist (`ls -R scenes/ scripts/ assets/` shows expected structure)
- `project.godot` lists all 8 autoloads in `[autoload]` section
- Project opens with zero errors — all 8 autoload stubs parse without GDScript errors
- `docs/.gdignore` and `specs/.gdignore` files exist and are committed
- `build/` is in `.gitignore` (run `git status` — `build/` does not appear)

# T001 — Create Godot 4 Project: Display 400×680 + Android Export

**Phase**: 1 — Environment Setup
**Session estimate**: 45 min

## Input
- Godot 4.3 stable installed (`godot --version` returns `4.3.x`)
- Android SDK + NDK configured (required for Android export template download)
- `word-storm/` git repo exists and is the working directory

## Steps
1. Open Godot 4 editor, create new project at `word-storm/` root — choose **Mobile** renderer
2. Edit `project.godot` directly (or via Editor → Project Settings) to set:
   ```ini
   [display]
   window/size/viewport_width  = 400
   window/size/viewport_height = 680
   window/stretch/mode         = "canvas_items"
   window/stretch/aspect       = "keep"

   [input_devices]
   pointing/emulate_touch_from_mouse = true

   [rendering]
   renderer/rendering_method = "mobile"
   ```
3. Lock orientation to portrait: Project Settings → Display → Window → Handheld → Orientation = `portrait`
4. Download Android export template: Editor → Export → Manage Export Templates → Download
5. Add Android export preset: Export → Add → Android
   - Package/Unique Name: `com.wordstorm.game`
   - Min SDK: 26
   - Target SDK: 34
   - Orientation: Portrait
6. Commit `project.godot` + `export_presets.cfg`

## Acceptance Criteria
- `godot --version` in terminal returns `4.3.x`
- Project opens in Godot editor with zero errors in the Output panel
- Play in editor: window renders at 400×680 portrait proportions
- Export dialog shows an Android preset with package name `com.wordstorm.game`
- `git log --oneline -1` shows the commit with both files

## Notes
- Do not add any scenes or scripts yet — folder structure comes in T002
- `export_presets.cfg` must not contain keystore paths or passwords (those come via env vars in T026)

# T009 — GameManager.gd: State Machine, Lives, Speed Progression

**Phase**: 2 — Core Tile System
**Session estimate**: 90 min

## Input
- T008 complete: `Column.gd` emits `pile_overflow(column_id)` signal
- T002 complete: All 8 autoload stubs registered; `GameManager.gd` stub exists

## Steps

### 1. Replace the stub `GameManager.gd` with full Phase-2 implementation

```gdscript
extends Node

enum State { TITLE, WAITING, PLAYING, GAME_OVER }
enum SessionType { CLASSIC, DAILY }

signal state_changed(new_state: State)
signal life_lost(lives_remaining: int)
signal game_over
signal speed_increased(new_speed: float)

const BASE_SPEED:     float = 80.0
const SPEED_STEP:     float = 10.0
const SPEED_INTERVAL: float = 30.0
const MAX_SPEED:      float = 220.0
const MAX_LIVES:      int   = 3

var state:           State       = State.TITLE
var session_type:    SessionType = SessionType.CLASSIC
var session_seed:    int         = 0
var lives:           int         = MAX_LIVES
var speed_level:     int         = 0
var current_speed:   float       = BASE_SPEED
var elapsed_seconds: float       = 0.0
var best_score:      int         = 0
var active_tiles:    Array       = []   # flat list of all LetterTile nodes in scene
```

### 2. Implement `_process(delta)`
- Only runs when `state == State.PLAYING`
- Increments `elapsed_seconds`
- Computes `new_level = int(elapsed_seconds / SPEED_INTERVAL)`
- If `new_level != speed_level`: update `speed_level`, clamp `current_speed`, emit `speed_increased`

### 3. Implement `start_game(type: SessionType)`
```gdscript
func start_game(type: SessionType) -> void:
    session_type = type
    session_seed = _generate_seed(type)
    lives = MAX_LIVES
    speed_level = 0
    current_speed = BASE_SPEED
    elapsed_seconds = 0.0
    active_tiles.clear()
    _set_state(State.PLAYING)
```
- Daily seed: `int("".join(Time.get_date_string_from_system().split("-")))` e.g. `20260509`
- Classic seed: `randi()`

### 4. Implement `lose_life()`
- Called when `pile_overflow` is received from any Column
- Decrements `lives`
- Emits `life_lost(lives)`
- If `lives <= 0`: emits `game_over`, calls `_set_state(State.GAME_OVER)`

### 5. Connect to Column signals
- After scene tree is ready, find all Column nodes and connect their `pile_overflow` → `lose_life()`
- This wiring happens in the GameScreen scene (T015), not in GameManager itself — GameManager exposes `lose_life()` as a public method

### 6. Implement `_set_state(new_state)`
- Sets `state = new_state`
- Emits `state_changed(new_state)`

### 7. Implement `register_tile(tile)` / `unregister_tile(tile)`
- Column.gd calls `GameManager.register_tile(tile)` when spawning, `unregister_tile(tile)` just before `queue_free()`
- Keeps `active_tiles` accurate for the duplicate-cap check in Column._pick_letter()

## Acceptance Criteria
- Call `GameManager.start_game(SessionType.CLASSIC)`: `state` becomes `PLAYING`, `lives == 3`, `current_speed == 80.0`
- Wait 30 s in play: `speed_increased` fires, `current_speed == 90.0`
- Call `GameManager.lose_life()` three times: first two emit `life_lost`, third emits `game_over` and sets `state = GAME_OVER`
- Daily seed is deterministic: calling `start_game(DAILY)` twice on same day produces same `session_seed`
- `current_speed` never exceeds `MAX_SPEED = 220.0` regardless of elapsed time
- Run the T008 test scene with GameManager wired: losing 3 lives (3 columns overflow) transitions to a `print("GAME OVER")` confirm

## Notes
- `active_tiles` is a flat Array, not typed — Godot 4 typed arrays don't allow cross-script `LetterTile` references without preloading; untyped is fine here
- Do not load SaveGame in this task — best_score persistence is wired in T023
- The `pile_overflow → lose_life()` connection is made by the GameScreen scene in T015; GameManager does not auto-find Column nodes itself

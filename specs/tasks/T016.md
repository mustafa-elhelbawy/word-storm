# T016 — Write ParticleManager.gd + TileBurst.tscn

**Phase**: 4 — Scoring, Effects, HUD
**Session estimate**: 90 min

## Input
- T012 complete: `GameScreen.tscn` has an `EffectsLayer (Node2D)` node
- T014 complete: `WordValidator.word_valid` fires when a word is accepted
- T005 complete: `Palette.gd` has `COL_COLOURS` for per-column burst colours

## Steps

### Part A — TileBurst.tscn

Build `scenes/effects/TileBurst.tscn`:
```
TileBurst (Node2D)                  ← TileBurst.gd attached
└── Particles (GPUParticles2D)
```

`GPUParticles2D` settings:
- `one_shot = true`
- `emitting = false` (triggered programmatically)
- `amount = 16`
- `lifetime = 0.5`
- `explosiveness = 0.9`  ← emit almost all particles at once for a burst feel
- Process Material: `ParticleProcessMaterial`
  - `direction = Vector3(0, -1, 0)` (upward burst)
  - `spread = 180.0` (full sphere)
  - `initial_velocity_min = 80.0`, `initial_velocity_max = 200.0`
  - `gravity = Vector3(0, 200, 0)` (falls back down)
  - `scale_min = 4.0`, `scale_max = 8.0` (small square particles)
  - `color = Color.WHITE` (overridden at runtime by ParticleManager)

Create `scripts/TileBurst.gd`:
```gdscript
extends Node2D

func fire(colour: Color) -> void:
    $Particles.process_material.color = colour
    $Particles.emitting = true
    await get_tree().create_timer($Particles.lifetime + 0.1).timeout
    queue_free()
```

### Part B — ParticleManager.gd

Replace stub `scripts/autoloads/ParticleManager.gd`:

```gdscript
extends Node

const BURST_SCENE := preload("res://scenes/effects/TileBurst.tscn")

var _effects_layer: Node2D = null   # set by GameScreen after scene ready

func set_effects_layer(layer: Node2D) -> void:
    _effects_layer = layer

func emit_burst(world_pos: Vector2, column_id: int) -> void:
    if _effects_layer == null:
        return
    var colour := Palette.COL_COLOURS[clamp(column_id, 0, 4)]
    var burst: Node2D = BURST_SCENE.instantiate()
    burst.position = world_pos
    _effects_layer.add_child(burst)
    burst.fire(colour)   # fire() auto-frees after lifetime

func flash(overlay: ColorRect, colour: Color, duration: float) -> void:
    overlay.color = colour
    overlay.modulate.a = 0.4
    var tween := overlay.create_tween()
    tween.tween_property(overlay, "modulate:a", 0.0, duration)
```

### Part C — Wire into GameScreen.gd

In `GameScreen.gd._ready()`:
```gdscript
ParticleManager.set_effects_layer($EffectsLayer)
```

In `GameScreen.gd._on_word_valid(word, tiles, score)`:
```gdscript
for tile in tiles:
    ParticleManager.emit_burst(tile.global_position, tile.column_id)
```

In `GameScreen.gd._on_life_lost(lives)`:
```gdscript
ParticleManager.flash($FlashOverlay, Color.RED, 0.3)
```

In `GameScreen.gd._on_word_invalid(word)`:
```gdscript
# No flash on invalid — shake is the feedback (already in WordTray.shake())
```

Optionally: green flash on valid word submit:
```gdscript
ParticleManager.flash($FlashOverlay, Color(0.0, 0.8, 0.3), 0.2)
```

## Acceptance Criteria
- Spell and submit a valid 3+ letter word: coloured particle bursts appear at each destroyed tile's screen position, fade out within ~0.6 s, and the TileBurst nodes free themselves (no node leak — verify with Godot's Remote Scene Tree debugger)
- Burst colour matches the column colour (column 0 tiles → teal burst, column 2 tiles → amber burst)
- Losing a life: red flash briefly covers the full screen at 40% opacity, fades to 0 over 0.3 s
- No frame-rate drop during burst: Godot profiler shows ≤ 30 draw calls during a burst event
- No GDScript errors; `scenes/effects/TileBurst.tscn`, `scripts/TileBurst.gd`, `scripts/autoloads/ParticleManager.gd` committed

## Notes
- `_effects_layer` is injected by GameScreen after ready — ParticleManager must not auto-search the tree (scene structure may change)
- `one_shot + queue_free` pattern ensures no persistent particle nodes accumulate over a session
- If GPUParticles2D is too heavy for target devices, fall back to CPUParticles2D — same API, software renderer

**Phase**: 4 — Scoring, Effects, HUD

## Steps

### Part A — Expand HUD node tree in GameScreen.tscn

Replace the stub HUD with:
```
HUD (CanvasLayer, layer = 5)
├── ScoreLabel (Label)                ← "0", top-centre, font size 32, bold
├── ComboIndicator (Label)           ← "×1.5" / "×2" / "×3"; hidden when multiplier == 1.0
└── LivesContainer (HBoxContainer)   ← top-right, 3 heart icons
    ├── Heart0 (TextureRect or Label using "♥")
    ├── Heart1 (TextureRect or Label using "♥")
    └── Heart2 (TextureRect or Label using "♥")
```

Layout:
- `ScoreLabel`: anchored top-centre, y=12, font size 32
- `ComboIndicator`: below ScoreLabel, y=50, font size 20, hidden by default
- `LivesContainer`: anchored top-right, x=310, y=12, separation=8

If a heart sprite atlas is not yet available, use Label nodes with `♥` text in `Palette.COL_COLOURS[0]` (teal) — replace with sprites in T016/T023.

### Part B — HUD.gd script (or add HUD logic to GameScreen.gd)

Option: add HUD methods directly to `GameScreen.gd` for simplicity (no separate HUD.gd needed if code stays under 60 lines).

#### 1. Score count-up tween
```gdscript
var _displayed_score: int = 0

func _on_score_updated(new_score: int, delta: int) -> void:
    var tween := create_tween()
    tween.tween_method(
        func(v: int): _displayed_score = v; $HUD/ScoreLabel.text = str(v),
        _displayed_score,
        new_score,
        0.4   # 400ms count-up
    )
```

#### 2. Combo indicator
```gdscript
func _on_combo_changed(multiplier: float) -> void:
    var label := $HUD/ComboIndicator
    if multiplier <= 1.0:
        label.hide()
        return
    label.text = "×%.1f" % multiplier
    label.show()
    # brief scale pulse
    var tween := create_tween()
    tween.tween_property(label, "scale", Vector2(1.3, 1.3), 0.1)
    tween.tween_property(label, "scale", Vector2(1.0, 1.0), 0.1)
```

#### 3. Life-lost heart animation
```gdscript
func _on_life_lost(lives_remaining: int) -> void:
    # Dim the heart at index (lives_remaining) — 0-indexed from left
    var hearts := $HUD/LivesContainer.get_children()
    var lost_index := lives_remaining  # e.g. 2 lives left → heart at index 2 dims
    if lost_index < hearts.size():
        var tween := create_tween()
        tween.tween_property(hearts[lost_index], "modulate:a", 0.2, 0.3)
```

#### 4. Connect signals in `GameScreen.gd._ready()`
```gdscript
ScoreManager.score_updated.connect(_on_score_updated)
ScoreManager.combo_changed.connect(_on_combo_changed)
GameManager.life_lost.connect(_on_life_lost)
```

## Acceptance Criteria
- Score starts at 0; after valid word submission, `ScoreLabel` counts up smoothly to new score over ~0.4 s
- After 2 consecutive valid words: `ComboIndicator` shows "×1.5" with a brief scale-up pulse
- `ComboIndicator` is hidden at game start and hides again when combo resets
- Losing 1 life: the rightmost heart dims to 20% opacity with a 0.3 s tween
- Losing all 3 lives: all 3 hearts are dimmed, then game-over transition fires
- HUD elements do not cover the tile area (z-ordering via CanvasLayer layer=5 is correct)
- No GDScript errors; `GameScreen.tscn` and `GameScreen.gd` updated and committed

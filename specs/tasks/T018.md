# T018 — Write AudioManager.gd + Wire All SFX

**Phase**: 4 — Scoring, Effects, HUD
**Session estimate**: 60 min

## Input
- T002 complete: `assets/audio/sfx/` directory exists; `AudioManager.gd` stub registered as autoload
- T012 complete: GameScreen emits all game events that need sound
- Audio files must exist before wiring — if `.ogg` files are not yet added (T024 adds real audio), use the placeholder approach described in Notes

## Steps

### 1. Replace stub `scripts/autoloads/AudioManager.gd`

```gdscript
extends Node

const SFX_PATHS: Dictionary = {
    "tile_land":    "res://assets/audio/sfx/tile_land.ogg",
    "tile_select":  "res://assets/audio/sfx/tile_select.ogg",
    "word_valid":   "res://assets/audio/sfx/word_valid.ogg",
    "word_invalid": "res://assets/audio/sfx/word_invalid.ogg",
    "life_lost":    "res://assets/audio/sfx/life_lost.ogg",
    "game_over":    "res://assets/audio/sfx/game_over.ogg",
}

const POOL_SIZE: int = 8

var _pool: Array[AudioStreamPlayer] = []
var _sounds: Dictionary = {}   # name → AudioStream
var _enabled: bool = true
```

### 2. Implement `_ready()`
- Create 8 `AudioStreamPlayer` nodes, add as children
- Load each `.ogg` file from `SFX_PATHS` into `_sounds` using `load()`; skip gracefully if file missing (use `if FileAccess.file_exists(path)` guard)
- Load `_enabled` from `SaveGame.get_sound_enabled()` (stub returns `true` by default)

### 3. Implement `play(name: String) -> void`
```gdscript
func play(name: String) -> void:
    if not _enabled or not _sounds.has(name):
        return
    var player := _get_free_player()
    if player == null:
        return  # all 8 slots busy — skip (prefer silence over stall)
    player.stream = _sounds[name]
    player.play()
```

### 4. Implement `_get_free_player() -> AudioStreamPlayer`
- Iterate `_pool`, return the first player where `not player.playing`
- Return `null` if all are busy

### 5. Implement `set_enabled(value: bool)`
- Sets `_enabled`; if `false`, stops all currently playing sounds

### 6. Wire AudioManager calls in GameScreen.gd and LetterTile.gd

In `LetterTile.gd`:
```gdscript
# In _on_input_event, after emitting tile_tapped:
AudioManager.play("tile_select")

# In _land():
AudioManager.play("tile_land")
```

In `GameScreen.gd`:
```gdscript
func _on_word_valid(word, tiles, score):
    AudioManager.play("word_valid")
    ...

func _on_word_invalid(word):
    AudioManager.play("word_invalid")
    ...

func _on_life_lost(lives):
    AudioManager.play("life_lost")
    ...

func _on_game_over():
    AudioManager.play("game_over")
    ...
```

### 7. Commit `scripts/autoloads/AudioManager.gd`; update `LetterTile.gd` and `GameScreen.gd`

## Acceptance Criteria
- If `.ogg` files exist: all 6 sound events play their corresponding sound without error
- If `.ogg` files are missing: game runs silently with no crash (graceful skip logged in Output panel)
- With 8 rapid tile selects: no crash from pool exhaustion — excess events are silently skipped
- `set_enabled(false)`: no sound plays for any event
- `AudioManager` Output panel shows "loaded N sounds" where N is the number of `.ogg` files present
- No GDScript errors; committed

## Notes
- Real `.ogg` sound files are added in T024 — this task wires the infrastructure; test with silence or a copied placeholder `.ogg` (any valid `.ogg` file renamed)
- 8-player pool is sufficient: at peak play, the events that can fire in rapid succession are `tile_select` (max 8 taps before submit), `word_valid` (one per submit), and `tile_land` (staggered). 8 slots cover all real cases
- Do NOT auto-play tile_land for every frame of falling — only play it once when a tile's state transitions to PILED

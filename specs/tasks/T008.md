### Part B — Column.gd

Create `scripts/Column.gd`:

#### 1. Constants and member variables
```gdscript
extends Node2D

const MAX_PILE: int = 5
const LETTER_WEIGHTS: Dictionary = {
    "E": 12, "A": 9, "I": 9, "O": 8, "N": 6, "R": 6, "T": 6,
    "L": 4,  "S": 4, "U": 4, "D": 4, "G": 3, "B": 2, "C": 2,
    "M": 2,  "P": 2, "F": 2, "H": 2, "V": 2, "W": 2, "Y": 2,
    "K": 1,  "J": 1, "X": 1, "Q": 1, "Z": 1
}

signal pile_overflow(column_id: int)

@export var column_id: int = 0

var _pile: Array = []
var _rng: RandomNumberGenerator
var _spawn_timer: Timer
var _last_spawned_letter: String = ""
var _tile_scene: PackedScene
```

#### 2. `_ready()`
- Preload `LetterTile.tscn`
- Create `RandomNumberGenerator`, seed it with `GameManager.session_seed ^ column_id`
- Create `Timer`, set `wait_time` to `_rng.randf_range(1.5, 3.5)`, `one_shot = false`
- Connect timer `timeout` to `_spawn_tile`
- Start timer only when `GameManager` is in `PLAYING` state (connect to `GameManager.state_changed`)

#### 3. `_pick_letter() -> String`
- Build weighted letter pool: for each letter in `LETTER_WEIGHTS`, add it N times to an Array
- Pick via `_rng.randi() % pool.size()`
- Apply Q→U rule: if `_last_spawned_letter == "Q"`, return `"U"` immediately
- Apply duplicate cap: if same letter already appears ≥ 2 times in `GameManager.active_tiles`, re-roll up to 10 times
- Store and return the chosen letter

#### 4. `_spawn_tile()`
- Instance `LetterTile.tscn`
- Call `tile.setup(letter, point_value, column_id, GameManager.current_speed)`
- Connect `tile.tile_landed` to `_on_tile_landed`
- Set tile `position` to `SpawnPoint.position`
- Add as child of this Column node
- Randomise next timer `wait_time`

#### 5. `_on_tile_landed(col_id: int)`
- Append tile to `_pile`
- Update `PileIndicator` height: `pile_size / MAX_PILE * 580.0`
- If `_pile.size() >= MAX_PILE`: emit `pile_overflow(column_id)`

#### 6. `set_fall_speed(speed: float)`
- Called by GameManager on `speed_increased` signal
- Iterate all child `LetterTile` nodes currently `FALLING`, update their `fall_speed`

#### 7. `clear_pile(fraction: float)`
- Remove `ceil(_pile.size() * fraction)` tiles from the bottom of `_pile`
- Call `tile.destroy()` on each removed tile
- Update `PileIndicator`

### Part C — Wire up in a test GameScreen

Create a minimal `scenes/game/TestGameScreen.tscn` (temporary) with 5 Column instances at x positions [40, 120, 200, 280, 360]. Set each column's `column_id` export var (0–4). Verify tiles spawn and fall.

## Acceptance Criteria
- Run `TestGameScreen.tscn`: 5 columns each independently spawn tiles at random intervals (1.5–3.5 s)
- Tiles fall at `BASE_SPEED = 80.0 px/s` and stop when they reach y = 580
- After 5 tiles pile in any column, `pile_overflow` signal fires (add a `print()` listener to verify)
- Q is always followed by U in the same column within the next 2 spawns
- Weighted letter distribution: run for 30 s, print a count of spawned letters — "E" should appear more than "Z" by a clear margin
- No heap allocations in `_process`: Godot profiler shows stable memory (no per-frame spikes)
- `scenes/game/Column.tscn` and `scripts/Column.gd` committed

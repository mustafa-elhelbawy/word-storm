# T003 — Import UI Font (Orbitron or Space Mono)

**Phase**: 1 — Environment Setup
**Session estimate**: 20 min

## Input
- T002 complete: `assets/fonts/` directory exists

## Steps
1. Download **Orbitron** (preferred — geometric, game-feel) from Google Fonts:
   - URL: fonts.google.com/specimen/Orbitron
   - Download the variable font: `Orbitron[wght].ttf`
   - Fallback: **Space Mono Regular** (`SpaceMono-Regular.ttf`) if Orbitron feels too heavy at small sizes
2. Copy the `.ttf` file to `assets/fonts/ui_font.ttf`
3. Open Godot editor — let it import the font (`.import` file is generated automatically)
4. Create a `FontFile` resource or rely on the auto-import — verify it renders in the editor's Font preview
5. Create `assets/fonts/ui_font.tres` — a `LabelSettings` resource that references `ui_font.ttf` at size 24, colour white; this will be the default label preset used throughout the project
6. Commit `assets/fonts/ui_font.ttf` and `assets/fonts/ui_font.tres` (do NOT commit `.import` files — they are in `.gitignore`)

## Acceptance Criteria
- `assets/fonts/ui_font.ttf` exists and is committed
- In Godot editor, drag `ui_font.ttf` into a test Label's Font property — text renders in Orbitron (or Space Mono) with no fallback system font visible
- `assets/fonts/ui_font.tres` exists and is committed; opening it in the editor shows font size 24, colour white
- `.import` files are NOT committed (verify with `git status`)

## Notes
- Orbitron is OFL-licensed — include licence acknowledgement in `docs/credits.md` (create if it doesn't exist)
- Only commit the `.ttf` file; Godot regenerates `.import` on first open on each machine

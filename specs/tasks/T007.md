# T007 — Write LetterTile.gd (Fall, Tap, State Machine)

**Phase**: 2 — Core Tile System
**Session estimate**: 90 min

## Input
- T006 complete: `scenes/game/LetterTile.tscn` exists with correct node tree
- T005 complete: `Palette.gd` is available

## Steps

### 1. Create `scripts/LetterTile.gd` and attach it to the scene root

### 2. Define the state machine enum and member variables
```gdscript
extends Area2D

enum TileState { FALLING, PILED, SELECTED, DESTROYING }

signal tile_tapped(tile: Area2D)
signal tile_landed(column_id: int)

var letter: String = "A"
var point_value: int = 1
var column_id: int = 0
var fall_speed: float = 80.0
var state: TileState = TileState.FALLING
```

### 3. Implement `_ready()`
- Connect `self.input_event` signal to `_on_input_event`
- Apply `letter` and `point_value` to child labels
- Set `TileBackground` colour from `Palette.COL_COLOURS[column_id]`

### 4. Implement `_process(delta)`
```gdscript
func _process(delta: float) -> void:
    if state == TileState.FALLING:
        position.y += fall_speed * delta
        if position.y >= 580.0:           # pile zone y threshold
            _land()
```

### 5. Implement `_land()`
- Set `state = TileState.PILED`
- Emit `tile_landed(column_id)`
- Stop further processing (state check in `_process` handles this)

### 6. Implement tap handler
```gdscript
func _on_input_event(_viewport, event: InputEvent, _shape_idx: int) -> void:
    if event is InputEventScreenTouch and event.pressed:
        if state == TileState.FALLING or state == TileState.PILED:
            emit_signal("tile_tapped", self)
```

### 7. Implement `select()` and `deselect()`
```gdscript
func select() -> void:
    state = TileState.SELECTED
    $TileBackground.modulate = Color(1.5, 1.5, 1.5)   # brighten

func deselect() -> void:
    state = TileState.PILED if position.y >= 580.0 else TileState.FALLING
    $TileBackground.modulate = Color.WHITE
```

### 8. Implement `destroy()`
```gdscript
func destroy() -> void:
    state = TileState.DESTROYING
    var tween := create_tween()
    tween.tween_property(self, "modulate:a", 0.0, 0.2)
    tween.tween_callback(queue_free)
```

### 9. Implement `setup(p_letter, p_value, p_column_id, p_speed)` convenience method
Called by Column.gd (T008) immediately after instancing to initialise all fields before `_ready()` runs — or call it in `_ready()` after instancing if called before add_child.

### 10. Attach script to `LetterTile.tscn` root node, save, commit

## Acceptance Criteria
- Open a test scene, instance `LetterTile.tscn`, run: tile falls from top toward y=580, stops when it reaches the pile zone
- Clicking the tile in editor (with `emulate_touch_from_mouse = true`) causes `tile_tapped` signal to fire (visible in Godot debugger signal monitor)
- After `select()` is called: tile brightens visually
- After `destroy()` is called: tile fades out and disappears within ~0.2 s
- No GDScript errors in Output panel during any of the above
- `scripts/LetterTile.gd` committed; `scenes/game/LetterTile.tscn` updated with script attached

## Notes
- The `580.0` pile-zone y threshold must match the `PileZoneMarker` position defined in Column.tscn (T008) — if Column.tscn uses a different value, update this constant to match
- `fall_speed` is set by Column.gd at spawn time; the tile does not set its own speed
- Do not import Autoloads in this file — LetterTile knows nothing about GameManager

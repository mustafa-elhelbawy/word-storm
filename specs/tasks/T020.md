# T020 — Build GameOver.tscn (Score Display, Best Score, Ad Slot, Play Again)

**Phase**: 5 — Screens, Save, Export
**Session estimate**: 75 min

## Input
- T009 complete: `GameManager.gd` emits `game_over` signal
- T014 complete: `ScoreManager.gd` holds `score` and `best_score`
- T023 complete (or stub OK): `SaveGame.gd` can read/write best score
- T002 complete: `AdManager.gd` stub exists (always emits `ad_unavailable`)

## Steps

### Part A — GameOver.tscn scene tree

Build `scenes/screens/GameOver.tscn`:
```
GameOver (CanvasLayer)
├── DimBackground (ColorRect)         ← full 400×680, Color(0,0,0,0.6) semi-transparent
├── ScorePanel (PanelContainer)       ← centred, 320×280, rounded corners
│   ├── VBox (VBoxContainer)
│   │   ├── GameOverLabel (Label)    ← text = "GAME OVER", font size 32, centred
│   │   ├── FinalScoreLabel (Label) ← text = "Score: 0", font size 28, centred
│   │   ├── BestScoreLabel (Label)  ← text = "Best: 0", font size 18, centred
│   │   └── NewBestBadge (Label)    ← text = "✦ NEW BEST ✦", hidden by default, font size 16, amber
├── AdSlot (VBoxContainer)           ← centred, y = 400
│   ├── ContinueAdButton (Button)   ← text = "Watch Ad → +1 Life", hidden by default
│   └── NoAdLabel (Label)           ← text = "No ad available", hidden by default
└── PlayAgainButton (Button)         ← text = "PLAY AGAIN", size 200×56, centred, y = 510
```

### Part B — GameOver.gd

Create `scripts/GameOver.gd`:

#### 1. `_ready()`
```gdscript
var final_score := ScoreManager.score
var best := ScoreManager.best_score

$ScorePanel/VBox/FinalScoreLabel.text = "Score: %d" % final_score
$ScorePanel/VBox/BestScoreLabel.text  = "Best: %d" % best

# Animate score counting up from 0
var tween := create_tween()
tween.tween_method(
    func(v: int): $ScorePanel/VBox/FinalScoreLabel.text = "Score: %d" % v,
    0, final_score, 1.0
)

# Show new best badge
if final_score >= best and final_score > 0:
    $ScorePanel/VBox/NewBestBadge.show()
    # brief scale-in animation
    $ScorePanel/VBox/NewBestBadge.scale = Vector2(0.5, 0.5)
    var badge_tween := create_tween()
    badge_tween.tween_property($ScorePanel/VBox/NewBestBadge, "scale",
        Vector2(1.0, 1.0), 0.3).set_ease(Tween.EASE_OUT)

# Attempt to load rewarded ad
AdManager.load_rewarded()
AdManager.ad_unavailable.connect(_on_ad_unavailable)
AdManager.ad_reward_granted.connect(_on_ad_reward_granted)
$AdSlot/ContinueAdButton.show()
```

#### 2. `_on_ad_unavailable()`
```gdscript
func _on_ad_unavailable() -> void:
    $AdSlot/ContinueAdButton.hide()
    $AdSlot/NoAdLabel.show()
    await get_tree().create_timer(2.0).timeout
    $AdSlot/NoAdLabel.hide()
```

#### 3. `_on_ad_reward_granted()`
```gdscript
func _on_ad_reward_granted() -> void:
    # Restore 1 life and return to game
    GameManager.lives = mini(GameManager.lives + 1, GameManager.MAX_LIVES)
    # Clear 50% of piles in each column
    for col in get_tree().get_nodes_in_group("columns"):
        col.clear_pile(0.5)
    get_tree().change_scene_to_file("res://scenes/screens/GameScreen.tscn")
```

#### 4. Button signals
```gdscript
$AdSlot/ContinueAdButton.pressed.connect(func(): AdManager.show_rewarded())
$PlayAgainButton.pressed.connect(func():
    GameManager.start_game(GameManager.SessionType.CLASSIC)
)
```

#### 5. Add Columns to "columns" group

In `Column.gd._ready()`:
```gdscript
add_to_group("columns")
```

This allows GameOver.gd to find all columns without a direct scene reference.

## Acceptance Criteria
- After 3 column overflows (game over): GameOver screen appears with the correct session score counted up from 0 over ~1 s
- If the score beats the previous best: "✦ NEW BEST ✦" badge scales in
- "Watch Ad → +1 Life" button is visible initially; since AdManager stub always returns `ad_unavailable`, button hides and "No ad available" label shows for 2 s then hides
- "PLAY AGAIN" button: starts a new CLASSIC game, returns to GameScreen
- `SaveGame.get_best_score()` after a new-best game returns the updated score
- No GDScript errors; `scenes/screens/GameOver.tscn` and `scripts/GameOver.gd` committed

## Notes
- `ScoreManager.score` is read directly — no signal needed here since GameOver is only shown after the game ends
- `AdManager` stub emits `ad_unavailable` synchronously — `ContinueAdButton` will always hide in phases 1–4; real ad flow tested in T025
- Add `GameManager.start_game()` signal connection so GameOver scene can transition cleanly regardless of who triggers the new game

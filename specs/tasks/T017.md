# T017 — Combo Popup Tween + Speed-Up Banner

**Phase**: 4 — Scoring, Effects, HUD
**Session estimate**: 60 min

## Input
- T015 complete: HUD is built, `ComboIndicator` label exists
- T014 complete: `ScoreManager.gd` emits `combo_changed(multiplier)` and `score_updated(new_score, delta)`
- T009 complete: `GameManager.gd` emits `speed_increased(new_speed)`

## Steps

### Part A — Combo popup floating label

This is a floating "+2× COMBO!" label that flies upward from the WordTray area and fades out — distinct from the persistent `ComboIndicator` in the HUD.

Add to `GameScreen.tscn`:
```
ComboPopup (Label)    ← inside CanvasLayer layer=4, initially hidden (modulate.a = 0)
```

In `GameScreen.gd`:
```gdscript
func _show_combo_popup(multiplier: float) -> void:
    if multiplier <= 1.0:
        return
    var label := $ComboPopup
    label.text = "+%.0f× COMBO!" % multiplier
    label.position = Vector2(200, 520)   # above WordTray
    label.modulate.a = 1.0
    label.show()

    var tween := create_tween()
    tween.set_parallel(true)
    tween.tween_property(label, "position:y", label.position.y - 60.0, 0.6)
    tween.tween_property(label, "modulate:a", 0.0, 0.6)
    tween.tween_callback(label.hide)
```

Connect in `_on_combo_changed(multiplier)`:
```gdscript
func _on_combo_changed(multiplier: float) -> void:
    $HUD/ComboIndicator.text = "×%.1f" % multiplier if multiplier > 1.0 else ""
    $HUD/ComboIndicator.visible = multiplier > 1.0
    _show_combo_popup(multiplier)
```

### Part B — Speed-up banner flash

Add to `GameScreen.tscn`:
```
SpeedBanner (Label)    ← CanvasLayer layer=4, text = "⚡ FASTER!", initially hidden
```
- Font size 22, bold, colour `Color(1.0, 0.8, 0.0)` (amber)
- Centred horizontally, y = 300 (mid-screen)

In `GameScreen.gd`:
```gdscript
func _on_speed_increased(new_speed: float) -> void:
    # Propagate new speed to all columns (already exists from T012)
    for col in $ColumnArea.get_children():
        col.set_fall_speed(new_speed)

    # Show speed banner
    var banner := $SpeedBanner
    banner.show()
    banner.modulate.a = 1.0

    var tween := create_tween()
    tween.tween_interval(0.8)               # hold for 0.8 s
    tween.tween_property(banner, "modulate:a", 0.0, 0.4)
    tween.tween_callback(banner.hide)
```

## Acceptance Criteria
- Achieve a ×1.5 combo (2 consecutive valid words): a floating "+1.5× COMBO!" label rises 60px and fades over 0.6 s above the WordTray area
- Achieve a ×2 combo (4 consecutive): popup shows "+2× COMBO!"
- After 30 s of gameplay, the "⚡ FASTER!" banner appears, holds for 0.8 s, then fades out
- Both animations run simultaneously without interfering with tile fall or other tweens
- Popup label auto-hides after animation; no persistent label visible during normal play
- No GDScript errors; `GameScreen.tscn` updated and committed

## Notes
- `ComboPopup` and `SpeedBanner` are single reusable Label nodes — not instanced per event — because they can't overlap in practice (combo and speed events don't coincide)
- If a second combo fires while the popup tween is still running: kill the existing tween first with `tween.kill()` before creating a new one, or just let Godot's `create_tween()` auto-replace (test which looks better)
- Font size and colour for these elements should be consistent with `Palette.TEXT`
